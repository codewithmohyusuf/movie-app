# 📖 About

Movie Explorer is a responsive movie discovery web application that allows users to discover trending movies, search for their favourite titles, and browse movie information using data from **The Movie Database (TMDB) API**.

The application was developed to strengthen my frontend development skills by building a real-world React project focused on API integration, reusable components, state management, and responsive UI development.

Although inspired by a JavaScript Mastery tutorial, this repository represents my own implementation and learning journey. Throughout the project I gained practical experience working with React Hooks, asynchronous data fetching, modern project structure, and clean component-based architecture.

# 🚀 Getting Started

## Prerequisites

Make sure you have installed:

- Git
- Node.js
- npm

---

## Clone the Repository

```bash
git clone https://github.com/CodeWithMohYusuf/movie-explorer.git

cd movie-explorer
```

---

## Install Dependencies

```bash
npm install
```

---

## Start Development Server

```bash
npm run dev
```

The application will start on

```
http://localhost:5173
```

---

# 🔑 Environment Variables

Create a `.env` file in the project root.

```env
VITE_TMDB_API_KEY=your_tmdb_api_key
```

You can obtain a free API key from:

https://developer.themoviedb.org
